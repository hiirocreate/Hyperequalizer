# ハイパーイコライザー (HyperEqualizer)

動画・音楽の視聴を「より快適に」するための、Android用メディアプレイヤー
＋簡易動画編集アプリです。Kotlin + Media3(ExoPlayer)をベースに、
ジェスチャー操作、区間ループ、イコライザー、ボーカル/伴奏の個別音量調整、
簡易動画編集などを実装しています。

制作フロー(ご希望の通り):

1. このプロジェクト一式(zip)をダウンロード
2. GitHubにリポジトリを作成してアップロード(push)
3. GitHub Actionsが自動でAPKをビルド
4. ビルドされたAPKをAndroidスマホにダウンロードしてインストール

---

## 1. 実装状況について(最初にお読みください)

ご要望の機能はかなり多岐にわたる本格的なアプリ(動画/音楽プレイヤー＋簡易編集
＋AI音源分離)だったため、要望いただいた「一度に全機能を実装」の方針で
一通りすべての機能を実装しましたが、この場ではAndroid実機やAndroid Studioでの
実機ビルド確認ができない環境で開発しています。そのため:

- **プレイヤー機能(視聴・ジェスチャー・メモリ機能・お気に入り・プレイリスト)は
  標準的なAndroid/Media3のAPIのみで構成しており、安定して動作する可能性が高いです。**
- **イコライザー(帯域調整・重低音強調)も標準API(`android.media.audiofx`)のみで
  実装しており、安定して動作する可能性が高いです。**
- **ボーカル/伴奏の分離・個別音量調整**は「AI分離(TensorFlow Lite)→ダメなら
  簡易センターチャンネル抽出」という二段構えで実装していますが、AIモデル自体は
  同梱していません(理由は下記3章)。フォールバックのみでも動作しますが、
  分離精度は限定的です。
- **動画編集(トリミング/結合/分割)**はMedia3 Transformerという比較的新しい
  ライブラリを使っており、Media3のバージョンによって細かなAPIの差異が
  出ることがあります。GitHub Actionsでの初回ビルドでこの部分だけエラーが出た
  場合は、`app/src/main/java/jp/hyperequalizer/app/ui/editor/VideoExporter.kt`
  を調整することで解決できるよう、書き出しロジックをこのファイルに集約して
  あります。
- **バックグラウンド再生・通知操作・動画ポップアップ表示**はMedia3の
  `MediaSessionService`と`WindowManager`(オーバーレイウィンドウ)という、
  こちらも実機での動作確認ができていない領域です。ロジックは
  `app/src/main/java/jp/hyperequalizer/app/playback/`配下
  (`PlaybackService.kt` / `FloatingPlayerService.kt`)に集約してあるので、
  もし不具合が出た場合はこのファイルを教えてもらえれば調整できます。

つまり「土台は完成していて実際に動く可能性が高いが、特にAI分離と動画編集の
2箇所は実機ビルドで初めて細部の調整が必要になるかもしれない」という状態です。
分からないことは正直にここに書きましたので、動かない箇所があれば教えてください。
一緒に直していけます。

## 2. 実装した機能一覧

### 動画・音楽 共通プレイヤー
- シークバー、横スライドでの早送り/早戻し(スクラブ)
- 画面左側の縦スライドで画面の明るさ調整、右側の縦スライドで音量調整
- ダブルタップで10秒スキップ(右側=先送り、左側=早戻し)
- ピンチズーム
- 表示比率4パターン切り替え(元の比率 / 画面いっぱい / 切り取り拡大 / 元のサイズ等倍)
- 再生速度調整(0.5x〜3.0x、9段階)
- 区間(A-B)ループ機能(開始点・終了点を自分で設定)
- リピート再生(オフ/リストループ/1曲ループ)、シャッフル再生(リストループとの
  組み合わせでシャッフルしながらループ)。フォルダ別ページやマイリスト(プレイ
  リスト)、お気に入り、通常の一覧のいずれから再生を始めても、その画面に
  表示されているファイル全体がキューになり、次へ/前へ・リストループ・
  シャッフルが機能します(NEW)
- リピート・シャッフルの切り替えは再生画面だけでなく、再生中の通知からも
  行えます(NEW)。区間(A-B)ループは再生画面を閉じてバックグラウンド再生に
  切り替わった後も、設定した区間で効き続けます(NEW)
- お気に入り登録
- プレイリスト作成(複数作成・名称設定)、プレイリストからの再生
- **常時メモリ機能**: 再生位置・ループ区間・表示比率/ズーム・再生速度・
  イコライザー設定を常にRoomデータベースへ保存し、アプリを再起動しても
  直前の状態から再開します
- 動画/音楽ファイルの削除(端末のMediaStoreから削除)
- **バックグラウンド再生**: どのファイル(動画/音楽)を再生していても、
  アプリを閉じたり画面を消したりしても再生が継続します
- **通知からの操作**: 再生中は通知(およびロック画面)に再生/一時停止・
  前後スキップを備えたプレーヤーが表示され、そこから操作できます
- **動画のポップアップ再生**: 動画再生中に画面右上のアイコンから、
  他アプリの上に重ねて表示される小さな動画ウィンドウに切り替えられます。
  ドラッグで位置を、ピンチでサイズを変更できます
  (初回はOS側の「他のアプリの上に重ねて表示」権限の許可が必要です)
- **フォルダ別一覧(NEW)**: 「動画」「音楽」タブ上部の「一覧」/「フォルダ別」
  切り替えで、保存フォルダごとにまとめた一覧に切り替えられます。各フォルダ
  は共通のフォルダアイコンで表示され、タップするとそのフォルダ内のファイル
  だけの一覧が開きます
- **このアプリ上での非表示機能(NEW)**: ファイル一覧の「⋮」メニューから
  個別のファイルを、フォルダ別一覧の「⋮」メニューからフォルダ単位で、
  それぞれこのアプリの一覧から非表示にできます。実際のファイル・フォルダは
  一切変更・削除されません(端末側からは今まで通り見えます)。非表示にした
  項目は画面右上のメニュー「非表示の管理」からいつでも一覧確認・再表示できます
- **まとめて選択(NEW)**: ファイル一覧・フォルダ別一覧内のファイル・お気に入り・
  プレイリスト詳細のいずれの一覧でも、項目を長押しすると「まとめて選択」モードに
  入ります。以降はタップで選択のON/OFFを切り替えられ、画面下部に表示される
  操作バーから、選択した項目をまとめてお気に入り追加/プレイリストに追加/
  非表示/削除できます(お気に入り画面ではお気に入りから削除、プレイリスト
  詳細画面ではプレイリストから削除の操作になります)。バー左端の「×」または
  選択を全て解除すると選択モードを終了します

### イコライザー
- 端末対応帯域数に応じた帯域イコライザー(`android.media.audiofx.Equalizer`)
- 重低音強調(`BassBoost`)
- ボーカル/伴奏の個別音量調整(下記3章を参照)

### 動画編集(簡易)
- トリミング(開始点/終了点の設定)
- 分割(1クリップを2クリップに分割)
- 複数動画の結合(クリップを追加して1本に書き出し)
- 音声の無効化(クリップ単位でミュート)
- コピー(クリップの複製)
- 書き出し(端末のMediaStore「動画」に保存され、アプリ内の動画一覧からも
  そのまま削除できます)

### 動画からの音声抽出(NEW)
- 「動画」タブの各動画の「⋮」メニュー、または動画編集画面のメニューから
  「音声を抽出して保存」を選択すると、その動画の音声だけを単体の音声
  ファイルとして書き出せます
- 書き出した音声ファイルは端末のMediaStore「音楽」に保存され、アプリの
  「音楽」タブにそのまま表示されます(再生・お気に入り・プレイリスト
  登録・削除もそのまま可能です)
- 形式は **M4A(推奨)** と **WAV** の2種類から選べます。詳しくは次の
  「MP3について」を参照してください。

#### MP3について
Android標準のAPIには音声を「MP3形式にエンコードする」機能が含まれていない
ため(MP3の再生・デコードには対応していますが、エンコードへの対応は
ほぼありません)、外部のエンコーダライブラリを追加しない限り、アプリ単体で
直接 `.mp3` ファイルを作ることができません。今回はネットワーク制限のある
開発環境だったため、そうした外部ライブラリを検証なしに組み込むことは
避け、代わりに次の2形式で確実に動作する方法を実装しました。

- **M4A**: 動画内の音声データを再エンコードせずにそのままコピーするだけ
  なので、処理が一瞬で終わり、音質の劣化も一切ありません。多くのスマホの
  音楽再再生アプリ・PCの再生ソフトでも問題なく再生できます。
- **WAV**: 音声を一度デコードしてから無圧縮で書き出す形式です。あらゆる
  動画/音声コーデックから確実に書き出せますが、ファイルサイズは大きく
  なります(内蔵の変換なので長時間動画は先頭60分まで)。

WAV/M4Aファイルは、パソコンの iTunes・Windows Media Player・Audacity、
あるいはスマホの音声変換アプリなどで簡単にMP3へ変換できます。もし
アプリ内で直接MP3を生成する必要が強い場合は、LAMEなどのMP3エンコーダを
ネイティブライブラリとして組み込む対応も可能ですので、その際はお知らせ
ください(要ビルド確認)。

## 3. ボーカル/伴奏 分離機能について(重要)

ご相談した通り、「音楽と歌声を個別に音量調整する」機能はスマホ単体での
本格的なAI音源分離(Demucs/Spleeter等)は計算負荷が高いため、**事前処理
(曲ごとに1回だけ分離処理を行い、その結果を保存しておく)方式**で実装しました。

具体的な流れ:

1. プレイヤー画面の「イコライザー」を開き、「この曲/動画をボーカル分離処理する」
   をタップ
2. アプリが音声をデコードし、
   - `app/src/main/assets/models/vocal_separator.tflite` にTensorFlow Lite
     モデルを配置していれば、それを使って分離
   - 配置していない場合は「簡易センターチャンネル抽出」(ミッドサイド処理に
     よるカラオケ的手法)で自動的に代替処理
3. 分離結果(ボーカル.wav / 伴奏.wav)を端末内に保存し、以後はボーカル/伴奏の
   音量スライダーが有効になります
4. 分離結果は常時メモリ機能で保存されるため、次回以降は再分離不要です

**AIモデル自体は同梱していません。** 学習済みモデルには利用規約・ライセンスが
それぞれ存在し、こちらで無断で組み込むことができないためです。もし高精度な
分離を使いたい場合は、Spleeter(2stems)やDemucsなどをTensorFlow Lite形式に
変換したモデルファイルを `vocal_separator.tflite` という名前で
`app/src/main/assets/models/` に配置してください(モデルの入出力仕様は
`SeparationEngine.kt` 内のコメントを参照)。配置しなくても簡易分離モードで
その場で動作します。

簡易分離モード(モデル無し)は「完全な分離」ではなく、中央定位成分(ボーカルや
ベース・キックなど)をまとめて抽出する簡易的な処理のため、曲によって効果に
ばらつきがあります。あらかじめご了承ください。

## 4. セットアップ手順

### 4-1. GitHubアカウント・リポジトリの準備

1. [GitHub](https://github.com) にアクセスし、アカウントをお持ちでなければ
   新規登録してください(無料)。
2. 右上の「+」→「New repository」から新しいリポジトリを作成します。
   - Repository name: 例 `hyper-equalizer`
   - Public / Private どちらでも構いません
   - 「Add a README file」等のチェックは付けなくてOKです(このzipに含まれています)

### 4-2. プロジェクトをGitHubにアップロード

**方法A: Web上でzipをアップロードする(Gitコマンドを使わない簡単な方法)**

1. このzipを展開します
2. 作成したリポジトリのページで「uploading an existing file」(または
   「Add file」→「Upload files」)を選び、展開したフォルダの中身
   (`app`フォルダや`build.gradle.kts`など)をすべてドラッグ&ドロップ
   - **注意**: `HyperEqualizer`フォルダそのものではなく、その「中身」を
     リポジトリ直下にアップロードしてください
3. 「Commit changes」でアップロード完了

**方法B: gitコマンドを使う場合**

```bash
cd HyperEqualizer
git init
git add .
git commit -m "初回コミット"
git branch -M main
git remote add origin https://github.com/【あなたのユーザー名】/hyper-equalizer.git
git push -u origin main
```

### 4-3. GitHub ActionsによるAPK自動ビルド

このプロジェクトには `.github/workflows/android-build.yml` を同梱しており、
`main`ブランチにpushすると自動的にAPKがビルドされます。

1. GitHubのリポジトリページ上部の「Actions」タブを開く
2. 「Android APKビルド」というワークフローが実行されているのを確認
   (数分かかります)
3. 完了したら、そのワークフロー実行結果のページ下部「Artifacts」欄にある
   `HyperEqualizer-debug-apk` をクリックしてダウンロード(zip形式)
4. zipを展開すると `app-debug.apk` が入っています

もしすぐに実行されない場合は、「Actions」タブ→左メニューの
「Android APKビルド」→右側の「Run workflow」から手動実行できます。

### 4-4. スマホへのインストール

1. ダウンロードした `app-debug.apk` をAndroidスマホに転送します
   (Googleドライブ経由や、USBケーブルでのファイル転送など)
2. スマホ側で、その apk ファイルをタップしてインストール
3. 「提供元不明のアプリ」に関する警告が出た場合は、案内に従って
   このインストールのみ許可してください(設定 → アプリ → 特別なアクセス
   → 不明なアプリのインストール、から個別に許可する端末もあります)
4. インストール後、初回起動時に「動画/音楽へのアクセス」の許可を求められるので
   許可してください(これが無いとライブラリが表示されません)
5. 動画のポップアップ表示を使う場合のみ、初回タップ時に「他のアプリの上に
   重ねて表示」の許可画面が別途開きます。案内に従って許可をONにしてください

## 6. 既知の制限事項・今後の拡張ポイント

- バックグラウンド再生・通知/ロック画面操作・動画ポップアップ表示は実装
  済みですが、次のような制限があります。
  - ポップアップ表示は**動画のみ**対応です(音楽は元々バックグラウンドで
    そのまま再生されるためポップアップは不要です)。
  - ボーカル/伴奏の分離再生(下記)は、バックグラウンド再生・ポップアップ
    表示中は追従しません(画面を離れると通常の(分離前の)音声に戻ります)。
  - 通知をタップするとアプリのメイン画面(ライブラリ一覧)が開きます。
    再生中の項目を直接タップして開き直しても、同じファイルであれば
    再生位置は引き継がれます。
  - Android 13(API33)以降は通知の表示に「通知の許可」が必要です。
    アプリの初回起動時にメディアアクセス許可と合わせて確認されます。
    許可しなくてもアプリ自体やバックグラウンド再生は動作しますが、
    通知からの操作はできなくなります。
  - 端末やOSのバージョン、メーカー独自のバッテリー最適化機能によっては、
    バックグラウンドでの再生が数分〜数十分でOS側に停止されることが
    あります。継続して使いたい場合は、端末の設定でこのアプリの
    バッテリー最適化を除外することをおすすめします。
- ボーカル分離処理は、メモリ使用量の都合上、**音声の先頭8分まで**を対象と
  しています(`AudioDecoder.kt`の`maxDurationMs`で変更可能)。
- 分離後のボーカル/伴奏の同時再生は、内部的に2つのExoPlayerインスタンスを
  同期させる方式のため、ごく僅かなズレが生じる可能性があります
  (2秒ごとに自動補正しています)。
- 動画編集(Media3 Transformer)は比較的新しい実験的API(`@UnstableApi`)を
  使用しているため、依存ライブラリのバージョンによって細部の調整が
  必要になる場合があります(該当箇所: `VideoExporter.kt`)。
- 対応フォーマットはMedia3(ExoPlayer)が標準対応する形式に準じます
  (mp4/webm/mkv/mp3/m4a/flac/wav/ogg等)。aviなど一部の古い形式は
  端末やMedia3のバージョンによって非対応の場合があります。
- 「フォルダ別一覧」「非表示」機能について
  - フォルダの判定は、Android 10(API29)以降は`RELATIVE_PATH`、それより
    古いバージョンでは実ファイルパスの親ディレクトリ名から行っています。
    端末やAndroidのバージョンによって、同じ保存場所でも表示されるフォルダ名の
    書式(例: `Movies/Camera` と `Camera`)が異なる場合があります。
  - 非表示は「お気に入り」タブにも反映されますが、「プレイリスト」は
    ユーザーが明示的に選んで追加したものとして扱うため、非表示にしても
    プレイリストからは削除されません。
  - サムネイル(動画のフレーム/音声の埋め込みアートワーク)は一覧表示時に
    都度デコードしてメモリ内にキャッシュします。ファイル数が非常に多い
    場合、初回表示がやや遅く感じられることがあります。
- カラーテーマは仮のものです。お好みで`app/src/main/res/values/colors.xml`を
  差し替えてください。アプリアイコンは
  `app/src/main/res/drawable-nodpi/ic_launcher_bg_photo.png`を差し替えることで
  変更できます。
- データベースのバージョンアップ(v1→v2、非表示機能の追加)は既存データを
  保持したまま移行するマイグレーションを実装済みです。常時メモリ機能の
  再生位置・お気に入り・プレイリストなどは、アップデート後も引き継がれます。

## 7. 技術スタック
